# Vehicle Service Management System

## Project Overview

Vehicle Service Management System developed using SAP RAP (RESTful Application Programming Model).

## Features

- Create Vehicle
- Update Vehicle
- Delete Vehicle
- Manage Service Records
- Track Next Service Date

## Technologies Used

- SAP RAP
- CDS Views
- Behavior Definitions
- Fiori Elements
- OData Services

## Business Flow

Vehicle Creation
→ Service Record Creation
→ Service Tracking
→ Next Service Monitoring
